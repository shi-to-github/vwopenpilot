# C2 定速手柄探针包（已装车停车验证）

基于已核对的 Dragonpilot `beta2_sharan2` / `a6eed9e`，保留 V1 已验证的 EPS 横向计时复位逻辑。它只研究原车定速手柄，不接管油门、制动或 ABS，也不按前车自动调速。由于当前分支没有主界面/设置页源码，屏幕开关采用独立的 Android 悬浮窗；C2 原生设置菜单与导航倒计时仍未接入。

悬浮窗默认显示“六分钟修复版”。乘客点击“开启测试模式”后，会自动启动被动 CAN 记录，并**只在**原车定速和 C2 都接合、车速至少 70 km/h、连续 5 秒没有油门/刹车/手柄操作时，尝试一次 `GRA_Down_kurz` 减速短按。检测到 C2 的发送尝试后，立即回到 V1，并继续记录约 20 秒供事后核对。点击“关闭测试模式”也会回到 V1。没有自动加速步骤；加速位与实际步长先通过原车手柄被动日志验证。悬浮窗已在这台 EON 的 Qt 画面上出现；Android 开机广播启动悬浮窗，openpilot UI 启动时启动只监听本机的后台。

2026-10-01 的原地验证：悬浮窗开/关可切换模式，打开后记录器持续写入 JSONL，关闭后模式文件回到 `0`、心跳移除；完整重启后后台和悬浮窗服务自动恢复且测试默认关闭。**行驶中的一次减速探针、Panda 放行和原车实际调速都尚未验证**，因此这不是自动跟车版本。

| 模式 | 行为 |
| --- | --- |
| `v1`（模式文件不存在或为 `0`） | 原来的横向方案；不额外发送定速按钮。安装后的默认状态。 |
| `observe`（`1`） | 同上；配合独立日志记录原车手柄、定速速度与 C2 状态。 |
| `manual`（`2`） | 只有乘客运行 `press up` 或 `press down` 后，才尝试一次对应的 `GRA_Up_kurz` 或 `GRA_Down_kurz` 报文。 |
| `auto_once`（`3`） | 悬浮窗测试模式：一次自动减速探针；需后台服务持续写入心跳，服务停止或心跳过期就退回 V1。 |

`CarController` 每 0.1 秒读取一次模式。手动按钮指令 5 秒过期；每次原车定速接合最多尝试一帧，不会连续点按。手动探针的最低车速是 55 km/h，屏幕自动探针提高到 70 km/h；两者都要求未踩油门或刹车、未操作原车定速手柄，以及原车 GRA 计数器更新。读取不到 C2 的设定速度**不会**阻止这一次明确的测试，但会要求使用原始 `Motor_2` 报文与仪表人工判断结果；不会因此启用按前车自动调速。

被动记录器 `diagnostics/capture_cruise.py` 使用**不合并**的 `can`/`sendcan` 订阅，记录 `GRA_Neu` (906)、`Motor_2` (648)、`ACC_GRA_Anziege` (1386) 原始数据和按当前 DBC 解出的字段，还记录 C2 巡航、按钮事件与前车状态。`Motor_2` 的原车定速设定值候选字段为第 5 字节 × 1.28 km/h；必须和实际仪表变化核对，不能只凭 DBC 认定这台车使用相同定义。`sendcan` 只证明 C2 尝试交给 Panda，不能单独证明 Panda 已放行或原车已执行。日志不收 GPS、视频或 VIN。

装包后，乘客可在终端运行以下设备端脚本；**先记录、先手动拨原车手柄，对照日志确认位与步长，再考虑使用 `manual`**：

```text
python3 /data/pq46/probe_control.py mode observe
python3 /data/pq46/capture_cruise.py --seconds 1800 --output /data/pq46/logs/cruise-test-01.jsonl
```

记录器占用一个终端；另一终端可执行 `python3 /data/pq46/probe_control.py mark "仪表显示设定速度 110"`，把肉眼观察写入同一份 JSONL。确需人工发一次测试时，先 `mode manual`，然后由乘客执行 `press down` 或 `press up`；`status` 可查看模式。每次接合只允许一次探针，下一次需重新接合定速。结束后执行 `mode v1`。车辆停止、只原地打火时可检查脚本和原车手柄位，但不能验证调速动作。日志拷回电脑后可运行 `python tools/analyze_c2_cruise_trace.py <日志文件>` 提取按钮边沿与定速值变化；原始 JSONL 仍需保留以便核对。

`tools/manage_c2_v2_probe_package.py` 提供只读状态、从 V1 安装和回退 V1；默认只读，安装/回退需要显式动作，并验证设备分支、提交、文件哈希、更新保持和停车状态。Android 悬浮窗源码在 `overlay/android`，本地构建工具是 `tools/build_c2_probe_overlay.py`。安装后的默认模式仍是 V1；只有屏幕开关打开才会记录并等待一次减速探针。回退会保留行驶日志，恢复原 UI 启动脚本并移除悬浮窗应用、匹配本包哈希的诊断脚本和测试模式。`manifest.json` 锁定待装 Python 文件、启动文件与回退文件。
