## 三项功能

1. **横向择机复位。** 连续横向接合 180 秒后，开始寻找窗口。要求原始及限幅后的转向请求不超过上限的 10%，模型未来 2.5 秒预测的横向加速度不超过 0.3 m/s²，两侧车道线可信、当前位置接近中心，且没有驾驶员操作。条件连续维持约 0.75 秒后，发送 100 个 50 Hz 待机帧，即沿用之前的 2 秒 EPS 复位时长。待机期间每个转向控制更新仍检查需求；需求、车道条件或驾驶员输入变化时立即恢复正常受限输出，并等待 5 秒再找机会。中止不清除累计计时。若到原方案的 240 秒仍未成功复位，就用现有 C2 提示请求接管／软退出，不在弯中强制暂停。模型预测不能保证未来不会需要转向，这一新择机策略仍需日志验证。自然连续 2 秒零输出也会清除计时。
2. **普通定速前车调速。** 手动打开“开启前车调速”后，以 `Motor_2.Soll_Geschwindigkeit_bei_GRA_Be` 的回读目标作为驾驶员上限；真实车速沿用原车车速解析，不使用 Motor_2 的未知字节推算。前车可信并持续确认后，尝试 `GRA_Down_kurz` 减十；前车确认离开后，用 `GRA_Up_kurz` 加十或 `GRA_Recall` 加一逐步恢复，指令不超过保存上限。真实手柄优先，并在其操作结束后重新记录上限。实际车速至少 70 km/h、目标下限 60 km/h，首次动作前至少稳定 5 秒。最多 9 个原车计数器时隙的按下帧（候选 180 ms）和一个松开帧；一旦提前回读到目标变化就提前松开。每次都等 ECU 目标确认，未确认 2 秒、方向错误、步长异常或反馈中断就停止调速；这一接合内不能靠开关模式清除失败记录，需取消并重新接合巡航。无自动制动，不是完整 ACC；下坡、快速接近前车或较小速度差都可能需要人工控速。减十的粗步长不能精确跟随所有前车速度，量化也可能使加一无法获得本次确认。步长余量不足时不再恢复，因此目标可能停在保存上限下方约 2.56 km/h 内，而非强行补齐。
3. **自动日志和悬浮窗。** 开机默认“横向择机＋日志”，不发送调速按键。原车巡航接合时自动记录；停止后继续约 20 秒，单文件约 30 分钟轮换。屏幕显示寻找窗口倒计时、待机剩余时间、当前定速目标、保存上限及是否等待回读；另有“试−10”“试+10”“试+1”三种单次测试。测试模式和前车调速互斥，单次测试回读确认后返回默认模式。这里使用原来悬浮窗方案，未修改 C2 原生导航/设置二进制。新界面 APK 已安装，实际截图确认倒计时与三个按钮可见。

日志包含原始 GRA / Motor_2 / HCA / EPS 接收帧、Panda 返回回显、发送尝试、车速与原车目标、前车状态、Panda 状态、横向状态和操作事件，不记录视频/GPS/VIN。只轮换本版 `logs/v3-*.jsonl`，约最多 20 个文件或 500 MB，不删除之前探针日志。服务停止／模式心跳超过 3 秒后调速默认关闭；日志启动失败不允许打开调速。日志不能替代官方行驶记录。

## 尚未解决的实车疑点

日志已确认三个按钮位及真实短拨约 100–200 ms；原来注入的一帧获得 Panda 回显，但发动机设定目标没有变化。**本版把短拨延长为候选时序，不能保证发动机接受。** 原车中性帧仍会与注入帧并存，计数器、发送者来源或 ECU 对原车帧的优先级仍可能导致忽略；本包不屏蔽原车消息、不放宽 Panda，也不承诺“拒绝时必然毫无其它影响”。是否生效要比较发送序列、Panda 回显和 Motor_2 目标回读。

保留当前原版 NMS／夏朗 `minSteerSpeed = 50 km/h` 和警告滞回，因此仍可能在约 53.6 km/h 提示低速。本包不降低低速限制、不添加地图/匝道控制。不通过保持几秒车速猜测定速目标。

## 本地构建与之后安装

在 `D:\VWopenploot` 中执行：

```powershell
python -m unittest discover -s tests -v
python tools/build_c2_probe_overlay.py --package v3
python tools/build_c2_v3_package.py
python tools/check_c2_v3_package.py
```

产物 `artifacts/pq46-c2-v3-candidate.zip` 包含增量源码、签名 APK、V2 回退文件/APK、哈希清单及部署工具。APK 沿用原 V2 的 Android 签名；签名私钥不进入压缩包。

下面是之后接机的操作参考。本车已经是 V3，重复 install 会被拒绝；可读 status 或在需要时 rollback。先停妥车辆、保持 C2 脱离接合，读取状态；设备 IP 要用届时真实值，SSH 主机指纹须已核对：

```powershell
python tools/manage_c2_v3_package.py --ip <设备IP> --action status
python tools/manage_c2_v3_package.py --ip <设备IP> --action install --parked-ignition
```

只有必须原地打火供电时才使用 `--parked-ignition`，工具会读取 5 秒实时数据确认 P 挡、静止及 C2 未接合；普通停车模式可以省略。安装工具核对分支/提交、所有旧文件哈希、更新保持、启动脚本及待装文件；停止旧诊断服务后落盘，安装 APK，失败时尝试回退。不会强制绕过不匹配。**安装后须停车重启 C2 才加载新版控制模块**，再检查状态和界面；工具不自动重启车辆或 C2。首次启动调速依旧关闭。

回退使用同样停车条件：

```powershell
python tools/manage_c2_v3_package.py --ip <设备IP> --action rollback --parked-ignition
```

恢复旧 V2 四分钟／两秒横向逻辑、旧探针悬浮窗和启动辅助程序，保留所有行驶日志；回退后也须停车重启。设备原始完整备份另存于本地 `device-backups/original-20261001`，不包含在本压缩包中。
