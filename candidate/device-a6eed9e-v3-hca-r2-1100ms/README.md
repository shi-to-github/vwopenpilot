# HCA-r2-1100ms 本地候选

用户要求先将停止时间设为 1.1 秒。候选已生成，未连接、安装或重启 C2；当前设备仍运行原两秒 hca-r2-entry。

以已部署 r2 为固定哈希基线，改动三份本地文件：

- hca_timer_reset.py：默认 standby 1.1 秒，50 Hz 下连续 55 帧，版本 hca-r2-1100ms。
- carcontroller.py：暂停未开始时也把真实所需时长传给 Runtime，去掉 PQ 路径写死的两秒；暂停期间继续传递剩余时间。
- pq46_runtime.py：启动偏离预测改为 1.1 秒；模型未来转向评估为 1.3 秒，即暂停加 0.2 秒模型新鲜度余量。模型样本之间的预测边界做插值，避免漏掉窗口末端的转弯。

没有改变 150 秒搜索、240 秒软件接管门限、请求峰值中止条件、PID、巡航、Panda 或 EPS。此候选不是用户讨论的完整分阶段择机版本，也未证明 5N1 的最短复位时间。原先六次不足 0.62 秒的中止问题仍可能出现。

rollback/ 保留当前 r2 对应三文件，manifest.json 固定前后全部相关哈希。生成器 tools/build_hca_r2_1100ms.py；本地 8 项测试验证恰好 55 帧、短失活不误记完成、恢复及旧中止行为、预测边界插值、控制器时长传递和文件哈希。

日志审计与硬件超时证据见 ../../docs/EPS_TIMEOUT_AND_1100MS_CANDIDATE.md。
