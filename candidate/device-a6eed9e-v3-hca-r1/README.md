# C2 V3 横向择机修正 r1

本包基于实机 V3，升级 `carcontroller.py`、`hca_timer_reset.py`、`pq46_runtime.py` 三个文件。提供原 V3 三文件回退，APK、按钮界面、调速实现、Panda 安全策略及速度门限沿用 V3。

这是候选修正：离线验证与停车运行检查不能证明道路上能完成重置，也不能证明本车 EPS 内部计时实际已复位。

## 行为

- 180 秒开始搜索；原始与限幅请求均不超过 60/300（20%）、持续约 0.75 秒才开始。
- 未来 2.5 秒模型横向加速度最大 0.3 m/s²、车道置信度至少 0.6、近侧车道线至少 1.1 m、无换道/转弯意图。上述门限继续保留。
- 启动中心误差最多 0.25 m、中心位置估算变化速率最多 0.12 m/s，并检查按当前向外变化速率外推两秒后的中心误差。
- 暂停期间原始请求不超过 90/300（30%），中心误差最多 0.35 m，向外变化速率最多 0.18 m/s，还需满足按剩余暂停时间外推的 0.35 m 边界。以 0.15–0.35 秒历史模型点估算变化速率；数据失效或历史不足中止。
- 明确驾驶员输入、转向灯、踏板或 CAN 无效会阻止/中止暂停。恢复输出仍经过原有驾驶员扭矩与变化率限制。
- 控制器连续输出 HCA disabled 满 100 帧（50 Hz，2 秒）才确认本地复位；单帧失活、短暂退出或暂停中止均不清零。此计数不是 EPS 内部的复位确认，需配合原始 CAN 记录核对。
- 累计计时采用保守的活跃区间时长，短关闭间隙继续计时；240 秒接管兜底保留。临近兜底、已无时间完成两秒时不启动暂停。
- 计数器跨短暂退出保留；新增自然复位数、阻挡/中止原因、原始/限幅/输出请求、HCA 输出状态、车道几何与变化速率、驾驶员输入记录。

这些数值为此测试版候选，中心位置/变化速率来自模型估算及简单外推，不是车辆失去纠偏后的精确轨迹预测。下一次路测仍需核实成功率和中止原因。

## 部署和恢复

```powershell
python tools/manage_c2_hca_r1.py --ip <C2地址> --action install --parked-ignition
python tools/manage_c2_hca_r1.py --ip <C2地址> --action reboot --parked-ignition
```

安装前后对完整 V3 相关文件进行 SHA-256 校验、检查原分支/提交和更新暂停，并确认停车、Park 档、控制未接合。安装会关闭调速/测试模式，正常结束记录服务，然后更换三文件；重启后服务恢复，默认为横向＋日志。

```powershell
python tools/manage_c2_hca_r1.py --ip <C2地址> --action rollback --parked-ignition
```

回退恢复到此前 V3，不是更早的固定四分钟版本。回退后需停车重启；回到 V3 后再使用原 V3 管理工具可回退 V2。旧日志保留。

本地日志/API 的 `runtime.hca.version` 为 `hca-r1`；屏幕沿用原来的倒计时，没有新增开关。安装后的实际验证记录另存于 `docs/HCA_R1_DEPLOYMENT_20261002.md`。
