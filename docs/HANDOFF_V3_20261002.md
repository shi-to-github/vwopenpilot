## 已知装车状态

车上仍为 V2，主控制器 SHA-256 `96aa6f6e9eaa7ff454bd1b328fcdc667584fb656154429c7ae576e86cc3bd230`，HCA 模块 SHA-256 `378190184d923d72c02580f0b9dd42a0b802b5b1573af1084f79f36c501f57f1`。其横向逻辑是固定累计 240 秒，然后 100 个 50 Hz 零扭矩待机帧；旧机会方案并未部署。用户反馈超时退出已消失且未明显感到暂停。界面为 `nl.vwopenploot.probe` V2 Android 悬浮窗，本地后台 8765，Qt UI 脚本含启动 `/data/pq46/boot_overlay.py` 的钩子。自动更新保持已设置过，但后续安装必须再检查。

原始备份中 `interface.py` 的 NMS/夏朗门槛曾为 0；自动更新重新检出提交后恢复 50 km/h，V2 没再改变它。原版警告在 `minSteerSpeed + 1 m/s` 下启用，因此约 53.6 km/h 黄色低速警告是既有滞回；不是新增 53 km/h 控制下限。V3 保持此参数。

三个单帧探针有 Panda `src=128` 返回回显，而 Motor_2 目标不变，不能称 ECU 已接受。原车中性帧约 14 ms 后到达，且可能与注入帧同计数器。原生短拨持续 100–200 ms；实测 `GRA_Up_kurz` 对应 +10，`GRA_Down_kurz` 对应 −10，`GRA_Recall` 在原车定速接合时对应 +1。`Motor_2` byte 4 × 1.28 km/h 随手柄即时变化，已与 vEgo 区分；byte 3 在此车不能当实际车速。细节见 `CRUISE_PROBE_RESULTS_20261002.md`。

## V3 的边界

V3 源码 `candidate/device-a6eed9e-v3`；产物 `artifacts/pq46-c2-v3-candidate.zip` 和相邻 `.sha256`。已包含 APK、V2 APK、增量源码、回退源码及 `tools/manage_c2_v3_package.py`。Android APK 沿用 V2 证书，其 SHA-256 指纹为 `a5e5d21ee91526f8ce6eddd80b16bd81c08c9e7a5d5493823b7c4f8e28e8b35a`。本地 keystore 不入包。

- 横向 180 秒开始寻窗：原始/受限请求 ≤ 最大值 10%，模型未来 2.5 秒预测横向加速度 ≤ 0.3 m/s²，车道概率 ≥ 0.6、边界余量 ≥ 1.1 m、中心偏差 ≤ 0.25 m，无变道/驾驶员操作，并持续约 0.75 秒。进入待机后每个 50 Hz 控制更新复核，不满足立即恢复正常受限请求；中止不重置计时，等待 5 秒重试。2 秒完整待机才算复位。没有窗口时 240 秒用现有 `steerTempUnavailable` 事件请求接管／软退出，避免在需求较高处强制切断。
- 默认模式 base，仅横向择机＋日志；auto 须屏幕手动打开，跟踪视觉前车并保存真实发动机目标上限。实际车速门槛 70、目标下限 60；原车手柄优先，稳定 5 秒再发。9 个按下帧最长候选 180 ms，收到目标变化时提前松开，最多等待 2 秒目标确认。未确认或异常就停止这一接合内的调速；切换模式不清除失败，取消/重新接合才清除。前车缺失需新鲜有效数据持续 3 秒才恢复上限。不改 Panda/ABS，不自动制动，不做地图或低速限制变更。时序仍可能因原车中性帧、计数器或消息来源被拒绝。
- Backend 8766，模式心跳 3 秒失效；控制模块状态 `/data/pq46/v3_status.json`，模式 `/data/pq46/v3_mode.json`。Android 悬浮窗有开关、三个单次测试按钮和倒计时。V3 自动记录原车巡航状态，原始 HCA/EPS/GRA/Motor2/CAN/sendcan、Panda 状态、前车、计时器和控制阶段；轮换仅限自有 `v3-*` 文件，不删 V2 日志。日志启动失败禁止打开调速。
