## 为什么"零断连"足以判定 1.1 秒有效

方向机内部计数是**累加**的，而我们新增的软件计时每轮清零——两者只有在"1.1 秒够不够"这一件事上才会一致。若 1.1 秒**不足**：

| | 内部累计 |
| --- | --- |
| 第 1 轮 | 200 秒（1.1 秒 standby 未清除） |
| 第 2 轮 | 再累约 160 秒即触及约 360 秒 → **拒绝** |

也就是说，若 1.1 秒无效，**大约开车第 6 分钟**就会出现第一次助力丢失，此后每约 3 分钟一次。这恰恰是用户最初报告的症状（持续横向控制数分钟后提示接管、纠偏停止）。

而实测是 **3 小时 34 分、约 60 轮、0 次断连**。这个观测等价于把"1.1 秒能否复位"验证了约 60 次，而不是 1 次。结合历史锚点——**0.900 秒已证实不足**，**2.060 秒之后 EPS 恢复**——1.1 秒落在两个锚点之间且落在有效侧。

**结论：本车 5N1/0503 的 1.1 秒 standby 有效。** 可信度：驾驶员感知，中高；缺帧级复核。

同时"1.1 秒不扰人"印证了 55 帧这个时长选择：既长到足以复位，又短到驾驶员无感。用户判定 **1.1 秒相比原 2.0 秒是质的提升**——更短的暂停使择机窗口更容易满足，也让择机变得轻松愉快。

## 结论与冻结

r4 的控制策略被认定为**第一个稳定版**：

- 0–180 秒正常控制
